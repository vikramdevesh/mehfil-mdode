Drop playlist cover images here, named by playlist slug:

  salon-classics.webp   highway-anthems.webp   chai-tapri-mix.webp ...

Supported: .webp .jpg .jpeg .png .avif — square, 1600×1600 or larger, under ~400 KB (WebP recommended).
They are picked up automatically at build time; playlists without a file keep the generated gradient art.
Prompts for generating them: see COVER_PROMPTS.md in the project root.
